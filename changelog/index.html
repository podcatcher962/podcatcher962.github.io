更新记录

最新在最前 · 只记值得一提的改动，全量记录在各仓库的 Releases

首页卡片上的版本号是跟着实际发布走的。这里写清楚每次改了什么，方便你判断要不要更新。

2026 年 11 月

  • 11-27
    卷帙 v1.5.9Windows · Web 补上一版没盖住的一种写法：章节号和标题挤在同一行、标题里又带了一次章号（第1章 第1章:走向他的被窝），盗版站导出目录常这么排，所以上一版装上去还是「第几章重复」。现在分章收尾会把同号同单位的重复章号并成一个；号码不同（卷+章）、单位不同（章+节）不动，免得把层级压平。网页版顶栏版本号可以自查是否加载了新页面。
  • 11-27
    言札 安卓版 v0.6.4Android 多给一个「增强版」安装包：标准版 182.4 MB，用原来的 Paraformer 小模型，快；增强版 260.7 MB，换成 SenseVoice，自带标点、人名术语错得少，代价是慢两三倍。同一段 203 秒播客，标准版 767 字 / 8 秒，增强版 829 字 / 9.3 秒，「弗洛伊德、休谟、莱布尼茨、顿悟」这几个词增强版明显更接近原话。两个包是同一个 App 的两个版本，不能同时装，装哪个就把另一个替换掉；已转好的稿子都在「下载/言札」里，不会跟着丢。下载页可以自己选。
  • 11-26
    言札 安卓版 v0.6.3Android 安卓版第一次对外发布。手机上点一下开始说、说完出字；手机里已有的音频和视频文件也能转（mp3 / m4a / wav / amr / flac / ogg，视频自动抽音轨）；在文件管理或微信里长按可以直接送进来转。识别模型装在安装包里，不联网、不上传，飞行模式也能用。长音频自动分段并显示进度，随时可以取消，结果超过 100 字自动存一份到「下载/言札/」。这版同时改正了「关于」页里的模型许可标注：Paraformer 模型用的是 FunASR 模型许可 v1.1，此前误写成 Apache-2.0。
  • 11-22
    站点改版本站 拆成独立页面：「关于我」「免责与隐私」「更新记录」各有自己的地址；首页去掉 9 秒开屏，补上「精选入口」和最近更新；新增品牌化的 404 页；修正卡片上的授权标注与统计数字。
  • 11-21
    言札 v0.7.2Windows 视频里本来就带文本字幕的，可以直接把字幕轨导出来当稿子，不用再跑一遍识别。单轨直接导，多轨让你选；已有稿子时整份替换，并清空该文件的撤销记录，避免两份内容混在一起。
  • 11-21
    卷帙 v1.5.7Windows · 网页 修两处断行：一句话被硬换行切断的，接回整段；标点单独占一行的，接回上一句。整理电子书时不再出现「引号孤零零挂在段尾」。

Updates

Newest first · only changes you can feel; full history lives in each repository's Releases

Version numbers on the home page follow real releases. This page explains what changed, so you can decide whether to update.

November 2026

  • 11-27
    DeShelf v1.5.9Windows · Web Catches the layout 1.5.8 missed: the chapter number and the title on one line with the number repeated inside the title (第1章 第1章:走向他的被窝). Pirate-site contents pages are often written that way, so 1.5.8 still showed a duplicated number. Chapter names now collapse the repeated number when the number and the unit match; a different number (volume + chapter) or a different unit (chapter + section) is left alone so real hierarchy survives. The version in the web header tells you whether the new page loaded.
  • 11-27
    YanZha Android v0.6.4Android A second "enhanced" package: the standard build stays 182.4 MB on the small Paraformer model and is the fast one; the enhanced build is 260.7 MB and swaps in SenseVoice, which punctuates on its own and gets names and technical terms right more often, at two to three times the processing time. On the same 203-second podcast: 767 characters in 8 s standard, 829 characters in 9.3 s enhanced — Freud, Hume, Leibniz and "sudden insight" all come out recognisably closer in the enhanced build. They are two builds of the same app and cannot be installed side by side; transcripts already saved under Download/言札/ survive the swap. Pick either on the download page.
  • 11-26
    YanZha Android v0.6.3Android First public release of the Android build. Tap once, speak, tap again; audio and video files already on the phone can be transcribed too (mp3 / m4a / wav / amr / flac / ogg, audio pulled from video automatically); long-press in a file manager or WeChat to send a file straight in. The recognition models ship inside the APK — no network, no upload, works in airplane mode. Long audio is chunked with progress and can be cancelled, and any result over 100 characters is auto-saved to Download/言札/. This build also corrects the model licence label on the About page: the Paraformer model uses the FunASR model licence v1.1, previously mislabelled as Apache-2.0.
  • 11-22
    Site rebuildSite Split into separate pages for About, Disclaimer and Updates, each with its own URL. Removed the 9-second intro splash, added a featured entry row and recent updates. New branded 404. Corrected licence labels and tool counts.
  • 11-21
    YanZha v0.7.2Windows If a video already carries a text subtitle track, you can import it as the transcript instead of running speech recognition again. Single track imports directly; multiple tracks prompt a choice. Importing replaces the whole draft and clears that file's undo history.
  • 11-21
    DeShelf v1.5.7Windows · Web Two line-break fixes: sentences split by hard wraps are joined back, and punctuation left alone on a line is pulled back into the previous sentence.
