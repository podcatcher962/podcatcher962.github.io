怎么选

  • 只想把手机里的录音、微信语音、随手录的想法变成文字 → 装安卓版。装完就不用管网络，飞行模式也能用。
  • 要把播客、会议、采访整理成能交出去的稿子 → 用电脑版。分人、校对、导出字幕这些只有电脑版有。
  • 两个都想要也可以，只是不能同时装在一台手机上（见下）。

几个常被问到的事

  • 两个包能一起装在一台手机上吗？不能。它们是同一个 App 的两个版本，装其中一个会把另一个替换掉。你转好的稿子都在「下载 / 言札」里，换包、卸载都不会跟着消失。
  • 为什么版本号不一样（0.7.2 和 0.6.3）？两套完全不同的程序：电脑版是 Python 打包，安卓版是 Java 打包，界面、功能、发布时间各走各的。版本号不能对齐，对齐反而会让人以为是同一个东西。
  • 哪个更准？电脑版。它的模型更大，还能分人、逐句改；手机版为了装进手机用了小模型，安静环境下差别不大，术语、人名会更容易听错。
  • 会不会上传我的录音？不会。电脑版程序里没有联网代码；安卓版安装包没有 INTERNET 权限，系统层面就联不了网。这条可以直接在手机上验：设置里看应用权限。
