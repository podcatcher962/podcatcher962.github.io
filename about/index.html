关于我

永远的兰兰 · Lanlan Eternal

一个人，一台电脑，四十来个不打扰人的小工具。

我是谁

我叫永远的兰兰，网上一直用这个名字。

这里没有团队，没有公司，也没有融资。页面上这些东西都是我一个人写的，从最早的一个小工具开始，一个一个攒起来。中间有做废的、有半途放下的，留下来的就是你现在看到的这些。

清单里大概四十个：传统文化的、日常效率的、播客的，还有几个纯粹是我自己想玩的东西（比如把走线图放大到能看清每一根铜）。

为什么做这些

最开始是因为自己要用。找了一圈，能用的工具要么收费，要么要注册，要么把你的文件传到我看不见的服务器上。

后来慢慢成了习惯：遇到一个反复出现的小麻烦，就想把它做成一个双击就能用的小东西。做得多了，索性开一个页面全部摆出来，省得每次都要翻聊天记录找链接。

我相信工具应该长这样——不打扰、不收费、不要你的手机号、用完就关掉。做不到这几点的，我不会放到这个页面上。

怎么做的

几条自己定的规矩，几年下来基本没破过：

  • 能单文件就单文件。在线版就是一个 HTML，桌面版就是一个 exe，不写安装程序、不写注册表、不留后台服务。
  • 文件不出本机。在线工具在你的浏览器里处理，没有后端；桌面工具断网也能用。
  • 代码公开。源码都在 GitHub，每个项目的授权写在各自的 LICENSE 里，不是所有项目都一样。
  • 做好才发。改完自己先跑一遍，测过的才写进更新记录。没测过的功能宁可不上。

更新的节奏

不定时。有想法就做，做完再发，不会为了发版而发版。有时候一周几个，有时候一个月没有。

每个新版改了什么，都写在「更新」页；更早的记录在各仓库的 Releases 里。首页卡片上的版本号是跟着实际发布走的，不是装饰。

在哪找我

有问题、想要某个功能、发现 bug，都可以直接说。我不一定秒回，但会看。

如果只是某一个软件的问题，在那个软件的 GitHub 仓库提 issue 最快——那里能看到代码，也能看到历史问题。

常见问题

要收费吗？有内购吗？

不收费。没有内购、没有广告、没有「高级版」，也没有藏在设置里的订阅。

要注册账号吗？

不用。在线版打开就能用；桌面版下载解压就能跑，不写注册表。

我的文件会被上传吗？

在线版不会——所有处理在你的浏览器里完成，没有服务器接收。桌面版在本机处理，不主动联网。

为什么没有 Mac 版？

桌面版是用 Python 打包的，只能在对应系统上构建，没法交叉编译。Mac 包需要真机验证，目前还没做；源码是公开的，可以自己跑。

杀毒软件报毒怎么办？

没有代码签名的 exe 经常被误报，这是行业里常见的情况。源码公开，可以自己编译核对；如果不放心，就别运行。

能用在商业场合吗？

看具体项目的 LICENSE。默认只授权个人使用，用在商业场景前先看那个仓库里的授权说明。

为什么有的卡片没有版本号？

那是在线网页版，跟着页面一起更新，没有单独的版本号。

About

Lanlan Eternal

One person, one computer, and about forty small tools that stay out of your way.

Who I am

I go by Lanlan Eternal online. There is no team, no company and no funding behind this page — every tool here was written by me, one at a time.

The list is roughly forty items: traditional Chinese culture, everyday productivity, podcast utilities, and a few things I simply wanted to play with.

Why I build them

It started with my own needs. Most tools I could find were paid, required an account, or uploaded my files to a server I could not see.

So I made a habit of turning recurring small annoyances into something you double-click and use. Eventually I put all of them on one page, so I would stop digging through chat history for links.

I think a tool should be quiet: free, no sign-up, no ads, no phone number, and gone the moment you close it. Anything that cannot meet that does not belong here.

How they are built

  • Single file whenever possible. Web versions are one HTML file; desktop versions are one exe — no installer, no registry, no background service.
  • Your files stay on your machine. Web tools run entirely in your browser; desktop tools work offline.
  • Source is public. Code lives on GitHub, and each project has its own LICENSE — they are not all the same.
  • Ship only what was tested. I run every change myself before it goes out.

Release rhythm

Irregular. I build when there is an idea and publish when it is ready. What changed in each release is listed on the Updates page; older notes live in each repository's Releases.

Find me

Questions, feature requests and bug reports are all welcome. I may not reply instantly, but I read everything.

For a specific tool, opening an issue in its GitHub repository is fastest.

FAQ

Is it paid? Any in-app purchase?

No. No ads, no premium tier, no hidden subscription.

Do I need an account?

No. Web tools open and work; desktop tools run after unzipping.

Are my files uploaded?

No. Web tools process everything in your browser; desktop tools run locally and do not upload by themselves.

Why no macOS build?

Desktop builds are packaged with Python, which cannot cross-compile. A Mac build needs real-hardware verification; the source is public and you can run it yourself.

My antivirus flags the exe.

Unsigned executables are frequently false-positived. The source is public — build it yourself if you prefer.

Can I use it commercially?

Depends on the LICENSE of that specific project. Default is personal use only.
